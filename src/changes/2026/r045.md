# Release 2026_045 (2026-10-26)

This is a hotfix release containing all changes of [2026_044](./r044.md), and additionally the following changes:

## Impact

### 26.05

VMs will skip the release 2026_044 and install this release right away. No additional impact.


## NixOS 26.05 platform

- Pull upstream NixOS changes, security fixes, and package updates:
    - ruby_3_3: 3.3.9 -> 3.3.13
    - ruby: 3.4.9 -> 3.4.12

- ruby: Regexp compilation fixes related to GitLab's CVE-2026-89078, CVE-2026-93577, CVE-2026-97229 and CVE-2026-110264

  The ruby updates above fix security vulnerabilites concerning Regex processing in the Ruby interpreter. These ruby updates are required for the gitlab-19.4.3 security update to be effective.
